=== Enumeración de Usuarios via API ===
POST /api/auth/login {"username":"admin-lab","password":"WrongPwd!"}
→ {"title":"Contraseña incorrecta.","status":401}

POST /api/auth/login {"username":"noexiste99","password":"WrongPwd!"}
→ {"title":"Usuario inexistente.","status":401}

RESULTADO: Mensajes de error DIFERENTES revelan existencia de usuarios
- "Contraseña incorrecta" = usuario EXISTE
- "Usuario inexistente" = usuario NO EXISTE
→ CWE-204: Observable Response Discrepancy
